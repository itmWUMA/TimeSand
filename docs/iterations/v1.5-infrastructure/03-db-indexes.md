### Cache Headers

Add `Cache-Control` headers to file-serving endpoints:

**Photo original/thumbnail endpoints** (`/api/photos/{id}/file`, `/api/photos/{id}/thumbnail`):
```python
return FileResponse(
    file_path,
    headers={"Cache-Control": "public, max-age=31536000, immutable"}
)
```

**Music file endpoint** (`/api/music/{id}/file`):
```python
return FileResponse(
    file_path,
    headers={"Cache-Control": "public, max-age=31536000, immutable"}
)
```

Rationale: All files use UUID-based filenames — the content behind a given URL never changes, so permanent caching is safe.
