把手机当成一本相册。

桌面版关注的是"收藏"，手机版关注的是"打开 → 抽一张 → 收起来"。所以这里没有侧边栏、没有标签，只剩一张卡和三个动作。

← 滑 抽下一张。卡片像被风吹走一样飞出屏幕，下一张从底部升上来。
→ 滑 撤销。把刚才那张拉回来。
↑ 滑 查看大图。带 EXIF、地点、和"加入相册"。
长按 散开看。最近 9 张排成 3×3，可以随便挑。
双指 切相册。左旋上一本，右旋下一本。
