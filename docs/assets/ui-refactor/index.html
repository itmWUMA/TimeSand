02

设计原则

DESIGN TOKENS
Palette

深胡桃 + 一抹琥珀

整套界面只有一个强调色（暖琥珀），承担所有"现在 / 高亮 / 主行动"语义；其余靠深浅胡桃木与字号节奏。

Type

三套字 · 各司其职

衬线 Iowan Old Style 写标题与抒情段、无衬线系统字写正文、JetBrains Mono 写日期与 EXIF。

Aa 字 2019·05
Motion

漂浮 · 不打扰

背景始终有低速漂浮的微尘（motes），照片可作 Ken Burns 推拉，但所有控件保持克制——不做摇晃、不做粒子炸开。

FLOAT-UP · 22–35s · LINEAR

Voice

诗化 · 不说人话

抛弃"翻牌揭示 / 状态机 / 数据库" 这类术语，按动词与时间写——"抽下一张"、"散开看"、"多年以前的今天"。
